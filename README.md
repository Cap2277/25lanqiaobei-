# 2025年第16届蓝桥杯嵌入式省赛代码

本仓库旨在提供蓝桥杯嵌入式历届真题和部分模拟题的参考代码，涵盖省赛和国赛题目，帮助学生和爱好者学习嵌入式编程并备战比赛。这些代码按年份和题目编号组织，采用官方 CT117E-M4 嵌入式平台，主控芯片为 `STM32G431RBT6`，代码基于 HAL 库编写，开发平台采用 `STM32CubeMX + MDK`。

当前仓库中的 2025 年第 16 届省赛工程已整理到 `2025年16届/` 目录下。

## 项目介绍

- 适用平台：CT117E-M4 嵌入式竞赛平台
- 主控芯片：STM32G431RBT6
- 开发环境：STM32CubeMX + MDK + HAL 库
- 内容范围：历年蓝桥杯嵌入式竞赛真题（省赛&国赛）+ 模拟题
- 当前工程目录：`2025年16届`
- 主要目录：
  - `2025年16届/Core`：核心应用代码
  - `2025年16届/Drivers`：底层驱动
  - `2025年16届/MDK-ARM`：Keil 工程文件
  - `2025年16届/CODE`：项目相关补充代码

## 备赛建议

### 1. 基础学习阶段

- 建议先系统熟悉各个功能模块的使用方式
- 可以先通过视频资料把各个模块练习熟悉

### 2. 实战练习阶段

- 建议在 4T 评测网站把往年真题完整做一遍
- 做完真题后可以继续练习模拟题，优先主观题，后期再集中训练选择题
